BoostOwl is a WhatsApp-based platform that Indian small businesses use for orders, stock, invoices and chats. As a Software Engineer Intern, I rebuilt every screen for phones so it installs like a native app: it starts offline, asks before it updates so no typed work is lost, and sends push alerts even when the app is closed. That is 318 phone components, with the desktop app left unchanged.
